Play Turf: mascot avatar system, unified themes, hero carousel, auth hardening

Avatar system:
- 5 fluffy plush mascots (yeti/sky/blush/mint/buddy) generated from one SVG
  template via sharp (512px transparent WebP, ~14KB each)
- profiles.avatar_id column (supabase_avatar_system.sql, idempotent)
- centralized lib/avatars.ts config + ui/MascotAvatar.tsx renderer
- new /avatar selection screen (mobile-first grid, token-only colors)
- global integration: header, More menu, open-games players/host
- removed robohash avatar collection + memory-only picker

Unified theme system (Premium Teal / AMOLED Black):
- provider injects all token namespaces (--color-*, --l-*, booking vars)
- duplicate per-theme JSX removed (hero carousel rebuilt as one scroll-snap
  track with swipe/drag/arrows/dots/keyboard; autoplay kept)
- receipts/tickets/dashboards tokenized by semantic role; status colors
  theme-invariant and distinct from brand primary
- theme-token audit script (0 undocumented violations)

Auth hardening:
- signup outcome handling (duplicate/ambiguous detection), resend-confirmation
  UI with cooldown, submit double-click guards
- rate limiting: record only real HTTP rejections, never successes
- session preservation with epoch-guarded revalidation timer
- race-free auth callback; loginSchema/signupSchema relaxed to min-6
