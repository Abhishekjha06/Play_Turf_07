# Verified Google guidance (owner round-3 item 9)

Checked 2026-11-21 via Google Search Central documentation + current sources.
Shipped conflicts fixed the same day (see "Action" per row).

| Topic | Current guidance | Source | Action taken |
|---|---|---|---|
| Self-serving reviews | LocalBusiness/Organization entities are **ineligible** for review stars from reviews captured on their own site (policy since 2019). Markup may still be emitted for accuracy; expect no star rich results. | [Review snippet guidelines](https://developers.google.com/search/docs/appearance/structured-data/review-snippet), [LocalBusiness guidelines](https://developers.google.com/search/docs/appearance/structured-data/local-business) | Our SportsActivityLocation markup emits AggregateRating only from genuine rows (never the static column) and only when `seo_rating_markup_enabled` — accuracy-only, expectation documented. No conflict. |
| rel="next"/rel="prev" | **Deprecated since 2019** — Google ignores them; crawl via normal links. | [Pagination blog post (marked deprecated)](https://developers.google.com/search/blog/2011/09/pagination-with-relnext-and-relprev) | We never emitted them. No conflict. |
| FAQ rich results | **Restricted since Aug 2023** to well-known government/health sites; HowTo rich results removed entirely. | [HowTo/FAQ changes](https://developers.google.com/search/blog/2023/08/howto-faq-changes) | We never emit FAQPage markup. No conflict. |
| Sitemap priority/changefreq | **Google ignores both.** lastmod is used only when consistently accurate. | [Build and submit a sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap) | **Conflict fixed**: priority/changefreq removed from `generate-sitemap.mjs` and the dynamic sitemap; turf lastmod uses real `updated_at`. |
| Sitemap limits | 50,000 URLs / 50 MB uncompressed per file; use a sitemap index when larger. | Same sitemap documentation | Config caps at `sitemapMaxUrlsPerFile` 10,000 with a 50,000 hard cap (index splitting ships with Phase 6 monitoring). No conflict. |
| Dynamic rendering | **Deprecated as a long-term solution** — Google recommends SSR/SSG. Crawler-specific HTML is tolerated as a workaround but not recommended. | [Dynamic rendering docs](https://developers.google.com/search/docs/crawling-indexing/javascript/dynamic-rendering) | Our serve.js bot-HTML layer IS dynamic rendering — a known, documented trade-off of the CSR architecture. Mitigation: bot content and SPA content are parity-tested (round-3 item 6), and the parity suite + Phase 6 monitoring keep the two pipelines aligned. Migration to SSR is a Phase 6+ architecture decision for the owner. |
